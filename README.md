# 메르센 소수 찾기 프로그램

## 설명
이 프로젝트는 메르센 소수(Mersenne Prime)를 찾는 프로그램입니다.

메르센 소수는 2^p - 1 형태로 표현되는 소수입니다. (p도 소수)

## 기능
- 메르센 소수 검색
- 웹 기반 사용자 인터페이스
- Python 기반 계산 엔진

## 프로젝트 구성
- **HTML** (98.1%): 웹 인터페이스
- **Python** (1.9%): 메르센 소수 계산 로직

## 사용 방법
웹사이트에 접속하여 원하는 범위의 메르센 소수를 검색할 수 있습니다.

## 설치 및 실행
```bash
# 저장소 클론
git clone https://github.com/sihuju992-lab/-1.0.git
cd -1.0

# 필요한 패키지 설치 (필요시)
pip install -r requirements.txt

# 프로그램 실행
python app.py
```

## 요구사항
- Python 3.x
- (기타 필요한 패키지는 requirements.txt 참고)
