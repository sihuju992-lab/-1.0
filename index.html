메르센 소수 찾기

Mersenne Prime Finder

어떤 숫자(p)를 입력하면, 2^p - 1 모양의 메르센 소수를 찾아주는 프로그램입니다.

예: 31을 입력하면 2^31 - 1 = 2,147,483,647 을 계산합니다.

기능

  • 빠른 Lucas-Lehmer 알고리즘 적용
  • BigInt를 사용한 대용량 숫자 지원
  • 실시간 계산 진행 상황 표시
  • 메르센 소수 자동 검증

사용 방법

  1. 파일을 다운로드합니다
  2. 웹 브라우저로 HTML 파일을 엽니다
  3. 찾고 싶은 지수(p)를 입력합니다 (예: 31)
  4. "마법 시작!" 버튼을 클릭합니다
  5. 메르센 소수 결과를 확인합니다

팁: 지수가 클수록 계산 시간이 오래 걸립니다. 처음엔 작은 숫자(2-31)부터 시작해보세요!
